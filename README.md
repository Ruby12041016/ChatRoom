# ChatRoom 用户文档

## 1. 项目简介

本项目是一个基于 **C/S（客户端/服务器）** 模型的简易即时通讯系统。  
服务端采用 **主从 Reactor + 线程池** 架构，支持高并发连接；客户端提供交互式 CLI 菜单，支持账号管理、好友管理、群组管理和实时聊天功能。

**主要功能**：
- 账号注册 / 登录 / 注销 / 密码找回（邮件验证码）
- 好友添加 / 删除 / 屏蔽 / 备注 / 在线状态查看
- 群组创建 / 解散 / 申请加入 / 成员管理 / 权限分级（群主、管理员、普通成员）
- 私聊与群聊（文本、文件发送）
- 历史消息记录（支持翻页查看）
- 离线消息推送（上线后自动接收）
- 文件传输支持 **断点续传**（提高项）
- TCP 心跳检测
- 服务器日志记录

## 2. 编译与安装

### 2.1 安装依赖（以 Ubuntu 为例）
```bash
sudo apt update
sudo apt install build-essential cmake libmysqlclient-dev libhiredis-dev libglog-dev libcurl4-openssl-dev libssl-dev nlohmann-json3-dev
```

### 2.2 编译服务端与客户端
```bash
mkdir build && cd build
cmake ..
make -j$(nproc)
```

编译完成后，在 `build/` 目录下会生成：
- `chat_server`  —— 服务端主程序
- `chat_cli`      —— 客户端主程序

---

## 3. 服务端配置与运行

### 3.1 启动 MySQL 和 Redis
确保 MySQL 和 Redis 已启动，并创建数据库 `chat_room`（导入提供的 `chat_room.sql` 脚本，若未提供则需手动创建表，请参考文档中的建表语句）。

### 3.2 配置服务端
服务端默认使用以下参数：
- **主服务端口**：`8888`（TCP 长连接，用于聊天协议）
- **文件传输端口**：`2100`（FTP，用于大文件上传/下载）
- **MySQL**：`127.0.0.1:3306`，用户 `root`，密码 `123456`，数据库 `chat_room`
- **Redis**：`127.0.0.1:6379`，密码 `1204`，数据库 `0`

### 3.3 启动服务端
```bash
./chat_server
```

---

## 4. 客户端配置与运行

客户端支持在命令行指定服务端 IP 和端口下：

```bash
./chat_cli <服务端IP> <服务端端口>
```

例如：
```bash
./chat_cli 192.168.1.100 8888
```

若省略参数，默认连接 `127.0.0.1:8888`。

连接成功后，客户端会显示交互式菜单。

## 5. 功能使用步骤

### 5.1 账号管理
- **注册**：在未登录界面选择 `1`，输入用户名、密码、邮箱、手机号。
- **登录**：选择 `2`，输入用户名/邮箱/手机号 + 密码。
- **忘记密码**：选择 `3`，输入邮箱，接收验证码，然后重置密码。
- **查看个人信息**：登录后，在菜单 `5` 中查看自己的用户 ID。
- **注销账号**：登录后，在菜单 `5` 中选择“注销账号”可永久删除账户（所有数据将被清除）。

### 5.2 好友管理（登录后菜单 `2`）
- **查看好友列表**：显示所有好友的在线状态、屏蔽状态和备注名。
- **查看好友申请**：列出待处理的好友申请，可同意或拒绝。
- **添加好友**：输入目标用户名或 ID，可附加留言。
- **删除好友**：输入好友名称，解除好友关系。
- **屏蔽/取消屏蔽**：屏蔽后对方无法给你发私聊消息。
- **设置备注**：为好友设置自定义昵称。

### 5.3 群组管理（登录后菜单 `3`）
- **查看我的群聊**：列出已加入的群组及自己在群内的身份（群主/管理员/普通成员）。
- **创建群聊**：输入群名称和介绍，创建者自动成为群主。
- **申请入群**：输入群名称，可附加申请留言。
- **查看入群申请**：群主和管理员可查看待审批的申请。
- **审批申请**：同意或拒绝用户入群。
- **查看群成员**：查看所有成员及其在线状态。
- **设置管理员**：群主可将普通成员提升为管理员或取消。
- **踢出成员**：群主/管理员可移除其他成员（不能踢群主或管理员）。
- **退出群聊**：普通成员主动退群（群主不能退，需先解散）。
- **解散群聊**：群主解散群，所有成员被移除。

### 5.4 聊天功能（登录后菜单 `4`）
- **私聊**：选择 `1`，输入好友名称，进入私聊对话界面。在此界面可：
  - 输入文字发送消息
  - 输入 `./file` 进入文件操作子菜单（上传/下载文件）
  - 输入 `exit` 退出当前对话
- **群聊**：选择 `2`，输入群名称，进入群聊界面，操作同私聊。
- **查看历史消息**：在对话界面选择 `2`，可查看最近消息或加载更早记录（翻页）。

#### 文件传输子菜单（在聊天界面输入 `./file`）
- **上传文件**：选择 `1`，输入本地文件路径和远程保存名称，文件会通过 FTP 通道上传到服务器 `./files/` 目录，并自动生成文件消息通知对方（支持断点续传）。
- **下载文件**：选择 `2`，输入消息 ID，客户端会自动从服务器下载对应文件，并保存到本地 `./downloads/` 目录（支持断点续传）。

### 5.5 实时推送通知
当有好友申请、私聊、群聊消息、入群申请等事件发生时，客户端会实时弹出推送提示（不会打断当前操作）。

## 6. Docker打包

### 6.1 
``` bash
sudo docker compose up -d  #自动启动 chat_server
```
### 6.2 客户端启动

``` bash
sudo docker compose run --rm chat_cli 
```
